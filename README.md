## 规格怎么用

**你拿到的代码不会跟我的一样。** 函数名、文件结构、连用不用框架都可能不同，这不要紧：
规格里没有一条在规定怎么实现，每一条规定的都是「做成什么样我才认」。
做完照着文件最后那张验收单挨个过一遍，过了就是对的。

**这跟一段提示词的差别只有一条**：它有验收。提示词写完靠你眼睛看，规格写完能拿它判定实现对不对。

## 写过没有

一个本机跑的检索系统：把你自己写过的东西向量化，按**意思**搜，
问它「这个观点我以前写过吗」。书里第 5 章、第 8 章、第 10 章、第 12 章的动手做都拿它当靶子。

**我把自己的语料一起放进来了**：2018 年到现在已发布的 672 篇文章和漫画，
连同建好的索引和向量库。clone 下来跑起来就能直接搜，不用先喂东西进去。
想换成你自己的，把 `我的文件/` 换掉、重跑一次 `refresh.sh` 就行。

只收已发布的：未发布的草稿、没有公众号链接的存稿都不在里面。
