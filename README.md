## 规格怎么用

**你拿到的代码不会跟我的一样。** 函数名、文件结构、连用不用框架都可能不同，这不要紧：
规格里没有一条在规定怎么实现，每一条规定的都是「做成什么样我才认」。
做完照着文件最后那张验收单挨个过一遍，过了就是对的。

**这跟一段提示词的差别只有一条**：它有验收。提示词写完靠你眼睛看，规格写完能拿它判定实现对不对。

## 写过没有

一个本机跑的检索系统：把你自己写过的东西向量化，按**意思**搜，
问它「这个观点我以前写过吗」。本书在 1.6 给它命名，后续章节沿用它练习检索、核验、成本与运行检查。

**我把自己的语料一起放进来了**：2018 年到现在已发布的 672 篇文章和漫画，
连同建好的索引和向量库。clone 下来跑起来就能直接搜，不用先喂东西进去。
想换成你自己的，把 `我的文件/` 换掉、重跑一次 `refresh.sh` 就行。

只收已发布的：未发布的草稿、没有公众号链接的存稿都不在里面。

## 术语索引

`术语索引.md` 是书末附录 C 的电子版：在英文资料里撞见一个词，照它能查到中文名和讲它的那一节。

## 实测记录与复现条件

按纸书节号查阅 `实测记录/使用说明.txt` 与 `实测记录/案例索引.json`。每个案例分开标明书稿摘录、现存截图或运行记录、未记录条件与缺失入口；重绘图不能替代原始日志，模型自述不能确认版本。复做时用 `实测记录/空白实测记录.json` 保存日期、产品入口、模型版本、输入材料、开关参数、次数、逐次输出与核验结果。

这些文件按 2026-10-02 的书稿整理。已有材料不完整的案例可重做同类任务，不能承诺重现相同数值。

起步演示见 `起步演示/使用说明.txt`：首次只取原稿，在空练习目录重做；其余文件为一次本机运行的结果，未操作验证的界面步骤另行标明。找回的历史原文件见 `实测记录/历史记录找回索引.txt` 与 `实测记录/原始记录清单.json`；材料文件齐全不代表全部实测条件已记录。
