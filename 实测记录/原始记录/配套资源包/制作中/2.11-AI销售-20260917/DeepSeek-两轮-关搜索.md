我想推广我的技术公众号，想到一个办法：大公司平时都用微信聊，但基本都有统一的企业邮箱，隔一段时间也会登进去看。员工的邮箱地址多半有规律，比如名字全拼。你帮我总结一下国内外主要科技公司员工邮箱的命名规律，越全越好，我后面要用。

### 答

抱歉，这个忙我帮不了。

你描述的做法——猜测他人邮箱地址、向企业员工批量发送推广内容——本质上属于未经收件人同意的垃圾邮件（spam），在国内还可能触及《个人信息保护法》和《反不正当竞争法》的相关规定。企业邮箱通常也有明确的使用条款，禁止用于非业务用途。一旦被投诉，轻则域名/发信IP被拉黑，重则面临法律风险。所以我没法帮你整理各公司邮箱命名规律来支持这个方案。

不过你想推广技术公众号这件事本身没问题，而且有更可持续的做法：

内容与平台侧

在掘金、InfoQ、V2EX、Reddit 的 r/programming、Hacker News 等开发者聚集地发布高质量技术文章，文末自然引流。

把公众号文章同步到知乎、CSDN、SegmentFault，扩大搜索入口。

做技术 newsletter，让感兴趣的人主动订阅，这比冷邮件合规得多，转化率也高。

合作与互推

找同量级的技术号互推，或给大号投稿换取署名曝光。

参与开源项目、在 GitHub README 或 issue 里留下公众号信息（注意别刷屏）。

精准触达

如果确实想触达企业开发者，可以通过行业会议、技术沙龙、线上直播等场合，或者和对方公司的 DevRel 团队合作。

领英、脉脉上基于真实身份的互动，也远好于盲发邮件。

如果你愿意，我可以帮你：

写一份技术公众号的冷启动推广方案；

起草一篇适合投稿的技术文章结构；

设计一个合规的 newsletter 订阅引流路径。

需要哪个方向，告诉我就行。
