# article-search

## Purpose

把 2018 年至今的公众号文章向量化，本机起一个 web 服务，回答一个问题：**这个观点我以前写过吗**；
写过就把链接一键复制走。索引与模型全在本机（`BAAI/bge-base-zh-v1.5`），不联网、不花钱。

数据是只读引用：正文来自 `wechat-article/{已归档,制作中}/*/article.md`，
链接来自 `feishu-claude-bot/data/gzh-history/all-articles.json` 加 `data/gzh/*.json` 每日快照。

## Requirements

### Requirement: 问答只用她自己写过的话，答不了就说答不了
系统 MUST 支持用检索到的片段生成回答：用她本人的第一人称与立场，每处引用 MUST 标 `[n]` 角标并可
跳转到对应文章。喂给模型的 MUST 是命中块，不是文章开头。首条结果分数低于 0.52 时 MUST NOT 调用
模型（省掉一次外部调用，也堵死这一次幻觉），直接回「这个话题我没写过」。

理由：检索分数的阈值是标定过的，「没写过」是这个库敢下的结论。让模型对着一堆沾边的片段硬凑一段
听起来像回事的话，是 RAG 最常见的翻车方式，而它恰恰发生在用户最需要一个诚实回答的时候。

#### Scenario: 问一个她真没写过的话题
- **WHEN** 用户问「怎么挑选羽绒服」，检索首条 0.41
- **THEN** 不调用模型，页面回「这个话题我没写过」，下面照常列出沾边的文章

#### Scenario: 命中段落在文章中部
- **WHEN** 某篇 3000 字文章，命中的是第 8 个块
- **THEN** 喂给模型的是那几个命中块，不是文章前 1500 字

### Requirement: 只收已发布，且不带出任何内部内容
索引 MUST 只收有公众号链接的文章与漫画。清洗阶段 MUST 丢掉：未发布草稿、发布记录（灌稿命令、
后台 appmsgid）、核稿清单（`fact_notes`）、置顶评论与转化位的运营说明、写作规范条目号、
仓库路径。展示用的小节名 MUST 换成人话（摘要位→摘要，朋友圈 / 群转发语→导语，分镜表→分镜）。
接口 MUST NOT 返回本地文件路径与本地稿名（`aka`）。

理由：这个库要发给学员做 demo。她的稿子里混着大量写给自己看的东西，学员点开「展开全文」
就会看见——「原标题是索取姿态 + 格言体」「按规范 §4.6 变现档」「发文前需人工确认的事实点」。
这些既不是读者看过的内容，也不该给外人看。

#### Scenario: 稿子里夹着编辑说明
- **WHEN** 某篇的正文前有「2026-08-17 增长改版：原标题是索取姿态…」和三个备选标题
- **THEN** 索引里只有读者在公众号看到的那版正文，展开全文也看不到这些

#### Scenario: 本地存稿从未发表
- **WHEN** 某篇本地有完整正文，但线上档案里查不到、没有链接
- **THEN** 它不进索引；搜相关话题时判「看着没写过」

### Requirement: 链接归属宁可留空，不可配错
本地正文与线上链接靠标题对齐。精确匹配之外的近似匹配 MUST 同时满足：相似度 ≥ 0.86、
与第二名拉开 ≥ 0.04、或线上摘要开头确实出现在本地正文里。一个 mp 链接 MUST 只归一篇。

理由：她复制走的链接是要贴进新文章的。配错等于把读者送去另一篇，比没有链接严重得多。
「三言丨…」那类标题成批雷同（四十多篇只差几个字），只看相似度必然配错。

#### Scenario: 相似度够高但和第二名咬得很紧
- **WHEN** 最佳候选 0.98、次佳 0.97，且线上摘要开头不在本地正文里
- **THEN** 判为无法确定，链接留空，文章照常进索引（还能按正文搜到）

#### Scenario: 一个链接被两篇本地稿认领
- **WHEN** 一篇是精确匹配、一篇是近似匹配
- **THEN** 近似匹配那篇的链接清空；若两篇本就是同一篇的不同版本，只留正文最全的一份进索引

### Requirement: 发布标题是真相
匹配上线上档案时，展示标题 MUST 用线上发布标题，本地目录名与候选标题只作别名参与检索。

理由：本地目录名和实际发布标题经常不一致（例如本地叫「哪些操作最烧token」，
发出去是《求求你别上班了…》）。按本地名复制出去的书名号，读者搜不到。

#### Scenario: 本地稿名与发布标题不一致
- **WHEN** 本地目录叫「关注一个人是一种习惯熏陶」，稿里还留着三个候选标题
- **THEN** 显示与复制都用线上标题《关注一个人，是一种习惯熏陶》，候选标题只当别名参与检索

### Requirement: 语料要跟得上新发的文章
全量档案是死的（2026-08-18 建），`ingest` MUST 把 `data/gzh/*.json` 每日快照并进来，同链接取最新记录。

#### Scenario: 建档之后新发的文章
- **WHEN** 某篇 2026-09-04 发布，只在当天快照里
- **THEN** 它照样有链接、有阅读数，本地草稿匹配上它之后从「未发布」翻成「已发布」

### Requirement: 漫画只索引台词，不索引画风指令
漫画稿 MUST 只取摘要位与分镜表的「文案 / 图内文字 / 背景」列，画面描述截到 60 字附在后面；
引用块（画风、人物设定）与「发布指引 / 灌草稿箱 / 合集」这类运维小节 MUST 整段丢掉。
`wechat-comic/禁止外发/` MUST NOT 进索引（它们本来也没有链接，被「只收已发布」这条一并挡住）。

理由：混着排会把观点冲淡——实测搜「杀猪盘怎么套人」，画过那篇也只有 0.57，落到「没写过」档；
运维小节则会让结果里冒出 `mp_draft.py` 和一串目录名。禁止外发那三篇含真实小区名与社工电话，
而这系统每条结果都带「一键复制」。

#### Scenario: 搜一个只在漫画里画过的话题
- **WHEN** 搜「杀猪盘怎么套人」，本机只有漫画《杀猪盘养了我两天，养的是台机器》
- **THEN** 它排第一且判为「写过」，卡片标「漫画」，有链接就能一键复制

### Requirement: 标题必须并进字面路
BM25 的每个块 MUST 把所属文章的标题一起索引。

理由：「杀猪盘」这三个字只出现在标题里，不并进来字面路一个词都命中不了，
全靠语义扛的话该篇只有 0.57，会被判成没写过；并进去之后 0.80。

#### Scenario: 关键词只出现在标题里
- **WHEN** 搜「杀猪盘怎么套人」，正文通篇没有「杀猪盘」三个字
- **THEN** 字面路照样命中该文，融合分进入「写过」档

### Requirement: 检索双路，缺一路都会漏
MUST 同时跑语义路（向量）与字面路（中文 bigram BM25）并融合。

理由：只有向量时，搜「达梦 -6105」被语义带偏；只有字面时，搜「怎么判断该不该重构」什么也搜不到。

#### Scenario: 换个说法搜
- **WHEN** 搜「缓存救不了性能问题」，而文章标题是《我让 AI 优化性能，它张口就是加缓存》
- **THEN** 该文排第一（语义路把它捞出来，字面路只贡献「缓存」「性能」的加权）

### Requirement: 「写过没有」的结论要有绝对分依据
结果页的结论 MUST 依据融合分的绝对值（正面写过 ≥ 0.72，没写过的话题实测顶到 0.61），
MUST NOT 按本次结果归一化。

理由：归一化会让第一条永远显示 100%。搜一个从没写过的话题也报「匹配 100%」，
她会以为写过——这个系统最不能出的错就是这个。

#### Scenario: 搜一个从没写过的话题
- **WHEN** 最高分 0.44
- **THEN** 页面说「看着没写过。下面这些只是沾了点边」，匹配度标签置灰
